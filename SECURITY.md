# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities or leaked
credentials. Use GitHub's **Report a vulnerability** option in the repository's
Security tab.

Include reproduction steps, affected versions or commits, and the potential
impact. Do not include live credentials in the report; revoke exposed secrets
immediately.

## Supported versions

clipsmith is under active development. Security fixes are applied to the latest
commit on `main` only.
